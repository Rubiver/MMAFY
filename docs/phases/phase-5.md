# 페이즈 5 — 완성도와 출시 준비

## 목표

전체 흐름을 점검하고 성능·안정성·확장 준비를 갖춘 MVP를 만든다.

## 작업 순서

1. 전체 코드와 프로토콜을 검토하고 발견한 오류를 수정한다.
2. 중복, 복잡도, 모듈 경계를 개선하는 리팩터링을 수행한다.
3. 전체 코드를 다시 검토하고 잔존 버그를 수정한다.

## 작업 범위

- 25명 목표의 성능 측정과 병목 개선
- 입력 제한, 예외 처리, 접속 끊김, 상태 복구 점검
- 오디오와 HUD의 핵심 피드백 정리
- 확장 역할·아이템·함정을 위한 등록 구조 정리
- 서버 보안 점검: 이동, 처치, 상호작용, 임무, 사보타지, 투표
- 배포 환경변수, 운영 문서, 알려진 제한 정리

## 완료 기준

- 기본 게임 한 판이 로비부터 결과까지 반복 가능하다.
- 25명 목표 환경에서 최소 30 FPS와 초당 10~20회 네트워크 갱신을 확인한다.
- 서버 검증을 우회하는 알려진 치명적 입력이 없다.

## 테스트 체크리스트

- [ ] 전체 코드 검토와 오류 수정 완료
- [ ] 리팩터링 후 자동 테스트 전체 통과
- [ ] 두 번째 전체 코드 검토와 잔존 버그 수정 완료
- [ ] 25명 부하 및 핵심 게임 흐름 검증 완료
- [ ] Playwright MCP로 로비·게임·회의·결과 전체 화면 스크린샷 저장
- [ ] 사용한 개발 서버와 포트 정리
- [ ] 로그, resume, 체크리스트 갱신 후 커밋
