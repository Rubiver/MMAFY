# 페이즈 3 — 게임 규칙

## 목표

생존자와 마피아의 역할 배정부터 처치, 신고, 회의, 투표, 승패까지 한 판의 핵심 규칙을 완성한다.

## 작업 범위

- 인원별 마피아 추천과 방장 직접 설정
- 역할 비공개 배정과 진영별 정보 분리
- 서버 검증 처치, 시체, 사망과 유령 상태
- 신고와 긴급 회의, 토론·투표·결과 단계
- 동점 무추방, 건너뛰기, 중복 투표 차단
- 마피아 전원 추방 및 인원 역전 승리 판정

## 완료 기준

- 모든 참가자가 동일한 회의·투표·추방 결과를 본다.
- 사망자와 유령은 살아 있는 사람의 의사결정에 참여하지 못한다.
- 비정상 처치나 투표 요청이 서버에서 거부된다.

## 테스트 체크리스트

- [ ] 게임 상태 전환과 역할 정보 분리 테스트 통과
- [ ] 처치 거리·쿨타임·생존 상태 테스트 통과
- [ ] 신고, 투표 동점, 승패 판정 테스트 통과
- [ ] Playwright MCP로 회의와 결과 전체 화면 스크린샷 저장
- [ ] 사용한 개발 서버와 포트 정리
- [ ] 로그, resume, 체크리스트 갱신 후 커밋
