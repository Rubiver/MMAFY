# 페이즈 1 — 기본 3D 게임

## 목표

단일 이용자 환경에서 게임 맵을 탐색하고 장치를 바라보고 상호작용할 수 있는 3D 기반을 만든다.

## 작업 범위

- `codes/client`의 React, Vite, React Three Fiber 기반 구성
- 중앙홀과 발전실 등 최소 구역을 가진 시험 맵
- 캐릭터, 카메라, WASD 이동, 마우스 회전, 걷기와 달리기
- Rapier 충돌, 사다리와 기본 장애물 처리
- 공통 상호작용 감지와 거리 안내, 키 입력 구조
- 장치 상태를 표현할 공용 타입과 화면 상태 저장소

## 완료 기준

- 충돌을 통과하지 않고 3D 맵을 안정적으로 이동한다.
- 상호작용 가능 대상에 안내 문구가 나타난다.
- 이동과 카메라 입력의 기본 조작이 문서화된다.
