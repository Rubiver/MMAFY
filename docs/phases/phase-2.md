# 페이즈 2 — 멀티플레이 기반

## 목표

최대 25명이 방에 입장하고, 서버 권한 검증을 거친 이동과 접속 상태를 서로 볼 수 있게 한다.

## 작업 범위

- Node.js TypeScript 게임 서버와 방 생성·입장·퇴장
- 최대 인원과 방장 설정, 준비 상태, 게임 시작 전 대기 화면
- 공용 프로토콜과 클라이언트 연결 계층
- 초당 10~20회 이동 입력 전송, 서버 속도·위치 검증
- 다른 참가자의 위치와 애니메이션 보간 표시
- 접속 끊김, 재접속 정책과 오류 안내

## 완료 기준

- 25명 이하 접속을 거부 없이 관리하고 초과 입장을 막는다.
- 한 참가자의 이동이 다른 참가자에게 자연스럽게 보인다.
- 클라이언트 조작만으로 비정상 이동 결과를 확정할 수 없다.
