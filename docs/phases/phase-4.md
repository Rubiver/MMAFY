# 페이즈 4 — 환경 상호작용

## 목표

환경 장치가 추리와 생존 전략에 직접 영향을 주게 만들어 제품의 차별점을 구현한다.

## 작업 범위

- 공통 상호작용 계약과 서버 거리·권한·시간 검증
- 문 상태와 잠금, 전력 영향
- 발전기와 조명 상태 연결
- CCTV 사용 중 이동 제한, 통신·전력 의존성
- 마피아 전용 환풍구 연결 그래프
- 기본 개인·공동 임무와 진행도 집계
- 정전 사보타지와 복구 흐름

## 완료 기준

- 정전이 조명과 CCTV에 일관되게 반영되고 복구할 수 있다.
- 문, 발전기, CCTV, 환풍구, 임무가 서버 권한으로 동기화된다.
- 생존자 협력과 마피아 고립 전략이 한 판에서 가능하다.

## 테스트 체크리스트

- [ ] 장치 거리·권한·쿨타임 검증 테스트 통과
- [ ] 정전과 복구, 공동 임무 진행도 테스트 통과
- [ ] 환풍구 연결과 접근 권한 테스트 통과
- [ ] Playwright MCP로 정전 전후 전체 화면 스크린샷 저장
- [ ] 사용한 개발 서버와 포트 정리
- [ ] 로그, resume, 체크리스트 갱신 후 커밋
