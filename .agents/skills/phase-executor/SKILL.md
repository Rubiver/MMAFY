## 사용 시기

- 사용자가 특정 페이즈(phase)의 구현을 요청할 때
- 프로젝트의 단계별 개발을 진행해야 할 때
- 페이즈 문서에 정의된 작업을 실제로 코드로 구현해야 할 때

## 기능

- 페이즈 문서(phase-*.md)에 정의된 작업을 분석하고 구현
- 페이즈의 목표, 산출물, 검증 기준을 바탕으로 개발 진행
- 기존 코드베이스와 통합하며 구현 진행

## 실행 절차

### 1. 시작 전 확인

시작 전 반드시 다음을 확인합니다:

1. **미완료 문제 확인**: `./docs/unsolved-compound-log.md` 파일이 존재하는지 확인
2. **파일 존재 시**: 해당 파일을 읽어 아직 해결되지 않은 주요 문제사항을 파악
3. **파일 미존재 시**: 미완료 문제가 없는 상태로 진행

### 2. 페이즈 분석

- 페이즈 문서(phase-*.md)를 읽어서 목표와 산출물 확인
- 구현해야 할 항목과 검증 기준 파악
- 선행 페이즈의 산출물 중 필요한 것 확인

### 3. 구현 계획 수립

- 페이즈의 목표에 맞춰 구체적인 구현 계획 수립
- 우선순위 결정 및 단계별 실행 순서 정리

### 4. 구현 실행

- 계획에 따라 실제 코드 작성 및 수정
- 기존 코드베이스와 통합
- 필요한 경우 테스트 진행

### 5. 검증

- 페이즈 문서의 검증 기준을 모두 충족하는지 확인
- 산출물이 제대로 생성되었는지 확인
- 미완료 문제가 있었다면 해당 문제 해결 여부 확인

## 규칙

1. 모든 작업은 한국어로 문서화
2. 코드와 기술 용어는 영문 유지 가능
3. 기존 코드 스타일을 존중
4. 불필요한 리팩토링 금지
5. 미완료 문제 로그는 업데이트하여 후속 페이즈에 전달
6. 한 번에 모든 것을 구현하려 하지 않고, 점진적으로 진행
