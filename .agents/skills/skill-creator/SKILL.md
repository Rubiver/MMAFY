## 사용 시기

사용자가 새로운 스킬을 만들고 싶다고 요청할 때 이 스킬을 사용하세요.

## 스킬 생성 규칙

### 1. 파일 구조

SKILL.md 파일은 다음 두 부분으로 구성됩니다:

**상단: YAML frontmatter**

- `name`: 스킬 이름 (kebab-case, 예: `skill-creator`)
- `description`: 스킬의 역할과 목적을 간결하게 설명 (필수)

**하단: Markdown 본문**

- 스킬의 상세 설명, 사용 방법, 규칙 등

### 2. 스킬 이름

- 항상 kebab-case 사용 (예: `skill-creator`, `code-reviewer`)
- `name` 필드와 디렉토리 이름이 일치해야 함

### 3. 디렉토리 위치

사용자가 어떤 에이전트를 사용하는지 확인하고 다음 경로에 생성:

| 에이전트 | 디렉토리 |
| --------- | --------- |
| Claude Code | `./.claude/skills/스킬명/` |
| OpenAI Codex / Pi Coding Agent | `./.agents/skills/스킬명/` |

에이전트를 알 수 없으면 사용자에게 물어보세요.

### 4. 작성 언어

- 모든 내용은 **한국어**로 작성
- 코드와 기술 용어는 영문 유지 가능

### 5. 금지 사항

- 중국어 한자 절대 사용 금지
- 한글로 된 한자어는 허용 (예: 사용, 목적, 설명)

## SKILL.md 작성 방법

### 예시 구조

```markdown
---
name: 스킬-이름
description: 스킬의 간략한 설명
---

## 사용 시기

이 스킬을 언제 사용해야 하는지 설명.

## 기능

스킬의 주요 기능과 역할을 설명.

## 사용 방법

구체적인 사용 단계와 규칙을 설명.

## 규칙

지켜야 할 규칙과 제약사항을 나열.
```

### 본문 작성 팁

1. **`## 사용 시기`**: 언제 이 스킬을 활성화해야 하는지 명확히
2. **`## 기능`**: 스킬이 수행하는 작업을 나열
3. **`## 사용 방법`**: 단계별로 구체적인 지침 제공
4. **`## 규칙`**: 반드시 지켜야 할 제약사항 명시
5. 필요시 `## 예시`, `## 참고` 섹션 추가

## 실행 절차

1. 스킬 이름과 목적을 사용자로부터 명확히 파악
2. 에이전트 종류 확인 (모르면 질문)
3. 디렉토리 생성
4. SKILL.md 파일 작성
5. 모든 규칙 준수 확인 (kebab-case, 한국어, 중국어 금지 등)
